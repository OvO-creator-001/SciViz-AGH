# SciViz-AGH 0.4.2 安装与使用

SciViz-AGH 把论文摘录或文本整理成简要概述、学术/科普两套解释、可点击的关系图和来源说明。它在 AGH 中作为工具插件运行，结果是可以离线打开的 HTML 和 SVG。

## 1. 安装前准备

- 电脑已安装并能正常使用 AGH，已配置可用模型；安装者有插件管理权限。
- AGH 需支持 package.json 中的 agnes.plugins、插件工具、工作区文件接口，以及联网时使用的 net.fetchPublic。PDF 读取由 AGH 自己的文档读取工具提供。
- 本包在 Windows、Node.js 24.21.0 和 AGH 源码提交 `57d0c34b33527294042b7ab8a60d7c7c934e932e` 对应环境验证。插件声明 Node.js >=24；AGH 自带合适运行时的用户无需另装 Node。未做所有 AGH 版本与操作系统兼容保证。
- 无需 Git、GitHub 仓库权限、npm install、额外模型或付费图片 API。AGH 自身模型使用仍按你的账户计费。

## 2. 解压到 AGH 的工作目录

**先确认 AGH 后台实际使用的工作目录，再解压。这个目录不一定是 AGH 程序安装目录，也不一定是当前会话选的资料目录。**

如果你从 PowerShell 的 `D:\Apps\agh` 目录启动 AGH 后台，且没有指定其他工作目录，下例使用它作为工作目录。如果后台早已启动，后来切换 PowerShell 目录不会改变已有后台的工作目录。不确定时，查看启动配置/后台日志，或请安装 AGH 的人确认，不要猜路径。

在该目录下创建 `plugins` 文件夹，把 ZIP 解压进去。最终应当是：

```text
<AGH工作目录>/
  plugins/
    sciviz-agh-0.4.2/
      package.json
      README.md
      LICENSE
      src/
      ops/
      docs/
      demo/
      CHECKSUMS.sha256
```

Windows 解压器可能多套一层同名文件夹。以包含 `package.json` 的这一层为准；应能找到 `<AGH工作目录>\plugins\sciviz-agh-0.4.2\package.json`。

例如：`D:\Apps\agh\plugins\sciviz-agh-0.4.2\package.json`。

## 3. 在 AGH 页面中安装并启用

1. 打开你平时使用的 AGH 页面，进入 **设置 → 插件管理**。
2. 找到从来源检查/安装插件的入口，选择本地 file 来源。界面文字可能随 AGH 版本变化。
3. 输入下面这一整行（使用正斜杠）：

   ```text
   file:./plugins/sciviz-agh-0.4.2
   ```

4. 点击检查，确认预览中的插件是 `sciviz-agh`、版本 `0.4.2`，没有阻断项，然后确认安装。本地包可能提示来源未独立验证；结合提供方与校验文件决定是否信任。
5. 安装完成后开启插件，按 AGH 提示确认信任/启用及所需权限。安装完成但未启用时，模型还不能使用它。
6. 确认详情显示实际运行版本 `0.4.2`、运行状态 `running`、已信任 `trusted`，再打开会话使用。

**安装栏不要填写 ZIP 文件名、`D:\...zip` 或 `file:///D:/...`。** 本流程使用相对于后台工作目录的 `file:./` 目录来源。

如果安装界面没有 file 来源入口，但你有 AGH 源码版 CLI，可在确认的后台工作目录执行：

```powershell
# 下面路径只是源码版安装位置示例，请改成自己机器上的 AGH 路径
node D:\Apps\agh\packages\cli\dist\local\agnes.mjs install file:./plugins/sciviz-agh-0.4.2
```

确认安装后仍需到网页插件管理中启用。打包版 AGH 不一定有这个源码路径，优先使用网页入口或该发行版提供的 CLI。

## 4. 第一次使用

可以先双击包内 `demo/interactive.html` 看页面效果，无需启动 AGH。它明确标为教学合成示例，不是论文分析结果。`demo/diagram.svg` 是静态替代。

正式使用时，在 AGH 会话中上传 PDF，或让 AGH 读取它当前工作区内的论文文件，也可以粘贴一段文本。然后发送：

> 请用 SciViz-AGH 分步分析这份材料。先读取原文并说明实际读取范围，用 start_sciviz_analysis 创建草稿。整理简要概述、关键要点和关系图，同时给出学术与科普两套解释。对难懂术语用 research_sciviz_term 查找教材或机构背景：使用完整术语和简短公开学科 context，不发送论文原文。核对资料相关性，将实际采用的 web_* 写入术语 source_refs，不要为了有引用而引用无关资料。保存并审阅草稿，必要时修订，再用 render_sciviz_draft 生成页面，给我可点击链接和完整文件路径。

例如检索 Transformer，应加“深度学习、注意力机制”等 context；不要只检索 state 或 intersection 这样的歧义单词。

打开生成页面后：先看概述，切换学术/科普，阅读图前指南，再点击节点查看解释。解释旁的 `[original_*]`、`[web_*]` 可以跳转到资料。Tab、回车和方向键支持基础操作。未采用的联网候选默认折叠。

默认产物在本次 AGH 工作目录的 `evidence/sciviz-*` 中，每次生成新目录，不覆盖旧文件。HTML/CSS/脚本自包含，生成后可离线阅读；点击外部来源链接才需要网络。

## 5. 继续修改

在同一 AGH 会话中发送：

> 读取刚才的 SciViz 草稿，把第二个术语讲得更通俗，保留严谨版本、原文和来源。保存为新修订，再生成一份新页面。

草稿保存在工作区 `.sciviz-drafts`，按工作区和会话隔离，同一会话重连后可恢复。新会话不能直接读取另一会话的草稿 ID；可以重新分析，或明确提供先前生成的 content.json 供 AGH 使用。不要把含私人材料的草稿目录随插件转发。

## 6. 常见问题

| 现象 | 处理方式 |
|---|---|
| 找不到来源/找不到 package.json | 检查后台实际工作目录、解压层级，以及 `file:./plugins/sciviz-agh-0.4.2` 是否指向包含 package.json 的目录。 |
| 已安装但模型不会调用 | 确认插件已信任、启用且实际运行；刷新页面/新开会话，并明确指定使用 SciViz-AGH。 |
| AGH 不能读取 PDF | 先检查 AGH 的文档读取能力、文件路径和访问权限；本插件不自带 PDF 解析器或 OCR。可先粘贴可复制的文本试用。 |
| 弹出权限请求 | 审阅后按需要批准工作区文件/联网访问。插件不能跳过宿主策略；拒绝后相应操作会失败。 |
| 联网失败或没有合适来源 | 使用完整专业名词与学科 context，或提供公开教材/高校/机构 URL。可继续仅根据原文生成，并说明联网补充未完成。 |
| `[web_*]` 没出现在解释旁 | 请 AGH 核对背景资料后将实际采用的 ID 写入术语 source_refs，再保存和生成；仅搜索过不等于已采用，插件不会乱配引用。 |
| 旧页面没有新版效果 | 旧 HTML 不会自动更新，需要重新生成。 |
| 链接点击后打不开 | 复制 AGH 返回的完整 HTML 路径，在文件管理器中打开。远程 AGH 用户需从远端下载整个产物目录到本地。 |
| 已安装老版本 | 将新版本解压到新的目录，在插件详情选“从新来源更新”，输入新目录的 file 来源；确认实际运行版本。保留旧目录，可用 AGH 的回滚功能。 |

## 7. 能力边界与数据

- 默认不依赖 Wikipedia。部分明确术语优先读取《动手学深度学习》中文教材；其他术语检索学术站点。本机教材访问已验证，但不能保证所有网络可访问。无合适结果时明确失败，不用无关词条凑数。
- 学术/科普文字由 AGH 模型编写，插件负责结构、来源约束与呈现。联网成功、结构通过或生成图形，都不代表科学正确性已经验证。
- 图像是固定 SVG 教学示意与关系/数据图，不是任意文生图、真实分子重建或3D模型。数值图必须有输入数据和来源。
- 长论文需说明读取范围，扫描版 PDF 可能需要 AGH 已有读取能力；不声称自动完成全文解析。
- 检索会向外部网站发送术语和公开学科背景，不要填入私人摘录。论文由 AGH 当前模型与数据政策处理；本插件不另接模型 API。
- ZIP 不含账号凭据、用户论文、node_modules 或开发机配置。源码采用 MIT（见 LICENSE）；演示中的引用摘录归原来源作者所有。

## 8. 校验与版本

插件代码来源提交：`9964da2750e6082acabe7c01ab74e12a01c04d87`。当前0.4.2已通过36项代码测试、9个工具定义检查、中文教材真实读取和 Edge 离线页面检查。其他电脑仍需按上述步骤实际安装验证。

ZIP 旁的 `.sha256` 文件用于检查传输是否完整；包内 CHECKSUMS.sha256 列出文件哈希。PowerShell 可执行 `Get-FileHash -Algorithm SHA256 .\sciviz-agh-0.4.2.zip` 并与旁边校验文件比较。文件哈希不等于独立签名，ZIP 的哈希也不同于 AGH 安装预览的包完整性摘要。

支持信息：报告 AGH 版本、插件版本、具体错误及最短复现步骤；不要提供密钥、Token 或私有论文全文。
