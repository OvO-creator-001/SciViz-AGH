## 本次迁移

本次没有复制安装器、EXE、分形算法或旧项目业务插件。迁移的是经过重新实现的平台模式：

- AGH 插件的最小注册形态；
- 会话状态隔离与清理；
- 工作区发现的降级顺序与有界搜索；
- 错误类别与模型可修复性标记；
- 原生事件配对、顺序和产物新鲜度核验；
- 不依赖 AGH 或模型的离线替身测试。

## 暂不迁移

- Fracta-Proof 安装器和构建产物；
- C++ 分形/渗流数值引擎；
- 分形动画与 HUD 文案；
- 写死旧工具名与 epsilon 边界的 trace 验收逻辑；
- 面向旧插件的系统提示词。

## 后续候选

2D GIF/MP4 渲染管线可作为 Tripo 或 3D 生成失败时的降级方案，但应在 3D 主链路和质量 Schema 稳定后另行迁移。
