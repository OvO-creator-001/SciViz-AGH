# SciViz-AGH 两人任务清单 R1

日期：2026-10-12。依据：[免费优先方案R2](docs/product/SCIVIZ_PLAN_R2_FREE_FIRST.md)。A/B为姓名占位；小时为人时估算，不是完成记录。

## 基线与首版范围

main已有治理骨架；[PR #1](https://github.com/OvO-creator-001/SciViz-AGH/pull/1)包含待审查合并的AGH基础设施和trace核验，真实宿主接入尚待验证。估算以复用该PR为前提。

首版：人工核对的论文摘录/JSON → 证据与格式评估 → 2D SVG流程图 → 点击高亮、分层解释、来源查看的本地HTML → 验证报告。不要求3D、通用PDF/OCR、照片级插图、Tripo或折叠动画。免费核心无需GPU、付费密钥或运行时联网；AGH模型推理费用另列。

## 并行节奏与接口

1. D1：A01/B01先冻结契约（两人各3小时分别计入）；A开始探针，B准备样例与SVG。
2. D2—D3：A完成输入和规则；B完成SVG和页面主体，使用同一组JSON并行。
3. D4—D5：编排、来源、讲解联调，完成第一条端到端路径。
4. D6—D7：降级、离线验证、交叉审查和演示交接。
5. D8及各阶段机动时间：消化缓冲。日期是每天各6小时的估算窗口。

契约草案：content.json记录对象、关系与source_refs；assessment.json记录decision、recommended_format、limitations；manifest.json关联输入与产物校验值。A01/B01确定精确字段与格式版本。渲染器不重新推断科学事实，评估器不修改布局。接口变更先同步fixture；AGH阻塞时可继续CLI，但不得宣称宿主已通过。

## 首版完成定义

- [ ] 双方交叉审查、日志与复现完成；正式交接创建新版本，不覆盖旧证据/tag。
