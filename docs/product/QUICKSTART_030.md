# v0.3.0：多视图科学图解

不再要求所有主题适配波形。插件根据输入连接结构选择流程、分层或网络布局；有带来源的数值时，可组合柱状图、折线图、散点图。免费离线生成 SVG/HTML，无图像 API 或浏览器运行时依赖。

## 一次打开六类示例

在仓库根目录运行 Node.js 24+：

```powershell
node examples/generate-gallery-v3.mjs
```

打开返回的 `gallery` 路径。每次创建全新目录，旧页面不会覆盖。六个示例均为团队原创的合成教学夹具，不是真实论文实验：

| 表达需求 | 示例 | 渲染方式 |
|---|---|---|
| 算法/实验方法的单链步骤 | method.json | 横向流程与角色图形 |
| 研究问题拆分、分支和合流 | evidence-tree.json | 分层关系图 |
| 生态联系、反馈与交叉关系 | ecology-network.json | 环形网络与关系编号 |
| 同尺度比较不同方法 | model-comparison.json | 分组柱状图，零基线 |
| 随数值变量变化 | environment-trend.json | 折线图，只连接给定点 |
| 两变量观测分布 | material-scatter.json | 散点图，不拟合、不暗示因果 |

示例输入在 `examples/gallery-v3/`。也可单独运行：

```powershell
node src/cli.mjs generate examples/gallery-v3/model-comparison.json
```

交互包括：逐步讲解、概念上下游/单关系高亮、键盘选择、缩放、系列显示开关、数据点精确值、完整数据表、来源跳转。关闭 JavaScript 仍可阅读图形与解释。手机上图形区域可以横向滚动，避免缩成无法阅读的文字。

## AGH 使用指令

> 使用 SciViz 为这份材料生成离线互动图解。保留 3–8 个核心概念、关系与明确出处。按输入结构自动选择流程、分层或网络布局；为节点填写合适的抽象 visual_role。若材料含准确数值及单位，可添加柱状/折线/散点图并指向原表或段落。没有数值就不添加数据图，不编造数据或科学几何。直接生成，不等待 verified；完成后给出网页路径、版权说明和待核对事项。

图表类型由 AGH/调用者依据材料填写，插件不会仅凭标题推断测量值。自动布局只识别连接结构，不等于自动理解科学含义。专门的波叠加示意继续兼容，但不再是唯一可用图解。

## 可选接口

原 `schema_version=1.0` 向后兼容。节点可增加：

```json
"visual_role": "data"
```

支持 `concept`、`data`、`process`、`model`、`measure`、`entity`；未指定使用通用概念符号。图形都是抽象角色标识，不是真实分子结构、设备工程图或科学重建。

根输入可增加：

```json
"visualization": {
  "layout": "auto",
  "chart": {
    "kind": "bar",
    "title": "教学数据对比",
    "x_label": "示例条件",
    "y_label": "示例分数（无量纲）",
    "series": [{
      "label": "方案 A",
      "source_refs": ["s1"],
      "points": [{"x":"条件一","y":12},{"x":"条件二","y":18}]
    }]
  }
}
```

- `layout`：`auto | process | hierarchy | network`。单链自动选择 process，回连或较密集图选择 network，其余选择 hierarchy。强制 process 但实际含分支时保留结构并退回合适布局，页面解释原因。
- `chart` 可完全省略。支持 `bar | line | scatter`，1–4 个系列，每系列需来源引用，原始数值表同时输出。
- 柱形 x 是分类文本，2–12 点；不同系列的类别和顺序须一致。包括零基线，保留负值。
- 折线/散点 x、y 均为有限数值（绝对值 ≤ 1e12），2–40 点。折线 x 必须严格递增；保留数值间距，不按等间距类别绘制。
- 图表标题 ≤ 120 字符，轴名 ≤ 80，系列/类别 ≤ 60。轴名应带单位；同轴系列须在相同条件、量纲下可比较，这仍需人工科学复核。
- 不拟合、不外推、不生成误差棒、p 值或新采样点。切换系列不改变坐标范围，避免视觉夸大。

`verified` 仍可省略或为 false；先生成，后提示。版权说明在返回结果、manifest、SVG 注解和网页末尾保留。

## 边界

这是可复用图解语法，不是任意论文的专业插画生成器。当前依然需要 AGH/调用者整理结构化输入，3–8 节点、最多 16 边。不能声称已经达到所有领域的定制 3Blue1Brown 插图质量；没有实现任意几何/分子重建、通用公式排版、视频动画或科学真实性认证。高密度网络仍可能有交叉线，点击关系可单独追踪，E 编号与全文对应。

插件外部服务费用为零；AGH 自身的模型推理费用不包含在内。真实论文的数值提取、来源支持、单位可比性和科学解释仍需复核，不因生成成功而自动可信。
