# SciViz-AGH 项目方案修订 R2：免费优先与按需可视化

- 日期：2026-10-12（Asia/Shanghai）
- 状态：产品设计，尚未实现；R2 是方案修订号，不是软件发布版本。
- 修订依据：用户要求每项预期工具至少有一个免费基础替代，并优先选择免费方案；不强求3D。

## 1. 项目定位

项目名称：SciViz-AGH——论文可视化评估与互动科普内容生成插件。

一句话：依据论文及关联数据，判断哪些内容适合可视化，优先用免费工具生成可追溯的图表、示意图或互动页面，仅在空间表达确有收益且证据充分时使用3D。

核心能力：证据检查与呈现推荐、数据或规则驱动的内容生成、来源关联与结果验证。AGH提供工具调度与原生trace；插件提供领域评估、场景组织和验收规则，不宣称保存模型内部思维链。

## 2. 免费的定义与默认策略

“免费基础方案”指在已有普通电脑上无需购买软件或付费API即可运行；仍消耗本地计算、电力和维护时间。公开数据的访问免费不等于允许任意再分发。选定依赖版本后记录其许可证和数据条款。

完整基础路径不依赖限时试用、赠送额度、付费密钥或GPU。默认外部付费预算为0；不得在免费方案失败时自动切换付费服务。升级必须说明具体收益、所需数据、费用上限并取得用户授权。没有适合的免费自动方案时，允许降低自动化程度、使用人工输入或输出缺口报告，不能编造结果。

AGH软件与模型推理是两个成本来源。不能承诺AGH内的在线模型免费。插件核心设计为可由本地CLI直接调用；AGH若支持已验证的本地模型配置，则可接入，否则完整AGH闭环的推理费用需单列。CLI回放不能冒充AGH真实调用证据。

## 3. 预期工具与免费基础替代清单

下表是拟采用方案，不表示相关依赖已经安装或集成。优先复用现有Node.js；Python、OCR、本地模型等仅在确有需要时引入。

| 环节 | 默认免费方案 | 免费基础替代（更低依赖或更低自动化） | 可选升级与限制 |
|---|---|---|---|
| AGH调度与工具接入 | 现有AGH，按官方package.json的agnes.plugins及registerTool接入；模型费用另算 | 本地Node CLI调用同一业务核心，人工选择流程 | 在线模型按平台实际计费；CLI不替代AGH接入验收 |
| 论文文本提取 | 用户提供TXT/Markdown；文本PDF可用PDF.js | 人工复制方法、结论、图注和必要表格 | 商业文档解析仅在复杂版式确有需要时选用；基础版不承诺完整解析公式 |
| 扫描件OCR | 按需使用本地Tesseract | 用户人工转录关键段落并校对 | 云OCR不是默认；OCR结果需核对符号、数字和单位 |
| 语义提取和文案 | 规则模板与人工确认的结构化内容；AGH已有模型输出作为待核验建议 | 人工填写对象、关系、来源、讲解字段 | 本地模型可经Ollama等运行时选配，模型权重许可及硬件另核；商业LLM需授权 |
| 可行性评估 | Node规则引擎检查数据、来源、几何或拓扑条件 | 人工检查表并保存结论 | LLM可建议但不绕过硬条件；不强制依赖主观打分 |
| 科学数据 | 用户已有且获准使用的CSV/JSON/PDB/mmCIF；按需读取公共数据库 | 小型人工核对的表格或明确标为教学合成数据的夹具 | 无法取得论文匹配数据时报告缺口，不拿不相干数据冒充 |
| 流程、关系、层次示意图 | 结构化JSON生成原生SVG模板 | 基础HTML列表、表格与连接关系说明 | Mermaid可作免费布局增强；复杂自动布局为后续选项 |
| 定量图表 | SVG基础折线、散点、柱状图，带单位与来源 | HTML数据表和必要文字解释 | Apache ECharts等免费交互图表库按需引入；不从无坐标图片伪造精确数值 |
| 互动科普页面 | HTML/CSS/JavaScript、内嵌SVG、点击高亮和分层讲解 | 静态SVG加Markdown说明 | 不要求商业建站服务；基础页面应可本地打开 |
| 动画 | SVG/CSS/JavaScript时间轴或步骤切换 | 连续静态分镜和前后状态对照 | 无轨迹证据只能标为教学示意；MP4导出不列入首版必需项 |
| 分子和蛋白质展示 | 数据支持时使用3Dmol.js等免费渲染器 | 2D序列、残基表、结构片段示意；接触图仅在有坐标或接触数据时生成 | 展示不等于结构预测；核对链、残基、来源、组装与缺失数据 |
| 通用科学3D | Three.js程序化几何，坐标或尺寸来自数据或明确参数 | 等价2D投影、剖面、流程图和标签 | Blender可免费用于复杂离线建模；运行与学习成本更高，非首版依赖 |
| 生成式模型资产／Tripo | 默认以程序化基础几何或SVG图标满足表达需求 | 无模型占位卡和文字说明，保持信息完整 | Tripo仅作可选外部生成；免费替代不承诺同等美术质量，不能用于推断真实科学结构 |
| 图像与插图 | 原生SVG符号、示意插图；复用图像须有使用权并标来源 | 文本标签、线框和表格 | 商业文生图或本地扩散模型不是基础依赖；照片级效果不作为验收要求 |
| 验证和测试 | Node内置测试、结构约束、来源核对；浏览器人工检查 | 检查清单与领域人员抽查 | Playwright可作免费自动化增强；VLM检查不是科学正确性证明 |
| trace与交付证据 | AGH原生trace加现有Node核验器及文件哈希 | CLI运行日志与产物清单，明确标注非AGH轨迹 | 不需要商业可观测平台；哈希与日志字段不能独立证明来源真实性 |
| 分享、托管与归档 | 本地HTML/SVG/JSON打包交接，现有Git仓库保存代码及版本历史 | ZIP离线传递；浏览器截图保存示意预览 | 自托管可选；不假设私有GitHub仓库自动享有免费Pages或无限存储 |

以上每项能力至少保留一个无需付费服务的基础路径；“低级替代”降低精美度或自动化，不降低对科学事实的要求。

## 4. 呈现选择与可行性评估

不评判整篇论文是否“配得上3D”，而是针对一个讲解目标和一组证据选择表达方式。

| 内容与条件 | 优先输出 | 何时增加交互、动画或3D |
|---|---|---|
| 方法步骤、因果主张或系统关系 | 2D流程图、关系图；关联不擅自画成因果 | 点击查看来源、按步骤展开 |
| 实测数值、分布与对比 | 2D图表与原始数据表 | 参数筛选、范围选择；不为装饰增加第三维 |
| 层级、部件和组织结构 | 2D层次图或剖面图 | 遮挡和空间关系影响理解且数据充分时用3D |
| 有真实坐标的空间对象 | 按讲解目标选择2D投影或3D | 旋转、切片或距离测量有实际收益时用3D |
| 时间过程 | 有数据的时间图；没有连续数据则使用分镜 | 有轨迹数据才展示为实际运动，插值方法需声明 |
| 证据不足 | 缺口报告、已有证据摘要；有依据时附教学示意 | 不强制生成图，更不强制生成3D |

评估顺序：确认来源与对象一致性 → 检查目标所需数据 → 排除证据不支持的表达 → 比较免费方案的教学收益、资源与可实现性 → 返回推荐和限制。初期采用可解释的规则及人工确认，不把未标定分数称为概率。科学事实缺失不能被美观或低成本抵消。

首批试验集建议30—50个小案例，包含2D优先、确需空间展示、信息不足、对象不匹配；区分规则调整集与留出验证集。报告误放行、推荐一致性、无来源主张数量及生成成功率，不预写实验成绩。

## 5. 最小闭环及范围

首版使用一篇方法型论文的经人工核对摘录，生成“2D方法流程图＋点击高亮解释＋来源引用＋评估报告”。第二个输入使用缺少关键数据的案例，验证缺口报告和可用的替代表达。另设显式故障测试模式验证断网或无效输入的处理。

第一阶段：真实AGH注册探针；随后完成共享Node核心、人工确认的输入JSON、SVG渲染和轻量HTML页面。第二阶段：PDF提取、基础定量图表、规则试验集和受众测试。第三阶段：在前两阶段稳定后，接入一个数据充分的3D案例。Tripo、照片级插图、通用扫描PDF、完整折叠动画均不作为首版必需功能。

## 6. 拟议接口与数据（未实现）

对外业务工具拟为assess_visualization_feasibility与generate_visualization；后者取代仅支持3D的命名设想。当前仓库尚无generate_3d_content业务实现，因此不存在已发布业务接口迁移。

评估输入包含paper_excerpt、goal、audience、evidence_refs、可选结构化数据及constraints。拟议默认constraints：prefer_free=true、allow_paid=false、external_budget=0、offline_required=true。在线取数或付费升级必须显式改变相应约束。

评估输出包含recommended_format（svg_diagram/chart/interactive_2d/interactive_3d/evidence_report）、decision（supported/schematic_only/insufficient_evidence）、evidence_refs、missing_requirements、limitations、fallbacks。每个建议后端标记免费类别、网络需求、硬件需求及已知成本限制。

生成前验证准入条件，随后保存规范化内容JSON、SVG或HTML、来源映射、验证报告和产物清单。数据与展示分离，使标签、布局和讲解可编辑。3D资产仅在选中3D时导出；基础交付不要求GLB。

## 7. 科学质量、受众与恢复

每个关键场景对象、图表序列和事实标签关联论文位置或数据记录。固定事实层，按受众调整术语解释和信息密度；简化不能删去不确定性和适用条件。检查单位、数量、坐标转换、数据与标签一致性，科学含义由领域人员抽查。动态内容支持暂停或静态替代；颜色之外还应提供文字或图形区分。

免费方案失败顺序：降低布局复杂度 → 静态SVG/表格 → 含来源和缺口的文本报告。不得静默切换付费API，也不得为保证出图编造数据。3D失败时，只有存在有效投影或替代信息才能降级为2D。

拟议运行约束：本地默认单任务、核心生成超时上限30秒（设计目标，待实测；不含人工确认及AGH推理），超时返回部分产物和原因。若后续启用外部生成，须独立设置费用和等待上限、保存服务端任务ID，并防止重试重复计费；客户端超时不等于服务端取消。

## 8. 验收与交付

基础验收：在已安装Node和浏览器、无付费密钥、无需GPU、运行时断网的条件下，从固定输入生成可打开的SVG、互动HTML和来源报告；依赖提前准备且浏览器资源不从CDN加载。不得把人工步骤排除在说明之外，也不得声称自动完成所有论文解析。

另行验收真实AGH链路，记录宿主版本、工具发现、调用、结构化结果和原生trace；明确模型是否产生费用。比较2D首选、信息不足和失败恢复三类样例。分别记录核心生成耗时、端到端耗时、实际API费用和人工校对时间。

交付文件按内容分为：产品方案docs/product/；后续接口细化docs/architecture/；依据与标定docs/research/；源码src/；测试tests/；样例examples/；报告及trace evidence/；复现ops/；技术日志changes/；正式版本快照releases/。历史发布目录、tag和旧日志只读，新交接使用新版本。

## 9. 实现边界与后续选型核验

当前已有AGH通用基础设施、会话隔离、工作区发现和trace核验器；本文新增能力均为待实现设计。本次不安装依赖、不声称免费本地模型已能接入当前AGH、不声明Tripo的试用额度或价格。

集成前固定工具版本、检查许可证并完成最小探针。参考入口：[AGH](https://github.com/AgnesAI-Labs/agnes-harness)、[PDF.js](https://mozilla.github.io/pdf.js/)、[Tesseract](https://github.com/tesseract-ocr/tesseract)、[Mermaid](https://mermaid.js.org/)、[Apache ECharts](https://echarts.apache.org/)、[3Dmol.js](https://3dmol.org/)、[Three.js](https://threejs.org/)、[Blender](https://www.blender.org/)、[Playwright](https://playwright.dev/)。这些是选型资料入口，本修订不构成对各版本许可或第三方服务条款的审计。
