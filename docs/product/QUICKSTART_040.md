## 在安装新版后的 AGH 中使用

上传 PDF 附件或粘贴文本，发送：

> 读取这份材料，用 SciViz 的 start_sciviz_analysis 开始分步分析，默认科普模式。为难理解的术语联网查找背景，先搜索再阅读相关公开教材或机构来源；解释清楚之后保存草稿。页面顶部给出简要概述和关键要点，同时提供学术与科普两套文字。根据来源选择合适的教学示意，保留原关系图。保存后先检查一遍，必要时修改草稿，再生成页面。最后给我打开页面的链接和完整文件路径。

需要更严谨时指定“默认学术模式，重点解释定义、假设、适用条件和类比边界”。两种文字都在生成时编写，页面切换不额外请求模型。分步流程默认把页面放在当前 AGH 工作目录的 evidence/sciviz-*，无需另行指定源码仓库。若AGH弹出保存/访问的权限请求，需由你按意愿批准；拒绝后模型应停止对应操作，不自动重试。

后续直接提出：

AGH模型在工具调用之间分析和优化。没有独立模型API费用；AGH自身推理仍遵循当前账户计费。生成页面后无需联网；主动打开来源链接才访问网站。

## 联网行为

默认使用 academic 策略：给出完整术语和简短公开学科背景，例如 `query="Transformer", context="深度学习 注意力机制"`。匹配到的注意力机制、Transformer、交并比等术语优先读取《动手学深度学习》中文教材；其他术语通过 Bing 查询教材/学术站点，并过滤词典、翻译与无关结果。不要仅搜索 state、intersection 等歧义单词。只发送短术语及公开上下文，不传论文摘录。Wikipedia 仅保留显式可选入口，默认流程不依赖它。

本机此次通过 AGH Host 成功读取中文教材的 Transformer、交并比和注意力机制相关正文。通用 Bing 查询仍可能返回不相关内容：过滤后无合适结果会明确失败，不塞入词典词条。不能保证所有网络和学科都有可用资料，也不能把检索成功称为科学核实。

AGH 需核对并将实际采用的 `web_*` 写入术语的 `source_refs`；两种模式的解释旁会显示可点击的来源标签。未采用的候选资料默认折叠，原文与补充背景分组。读图指南已移到关系图上方。旧 HTML 不会自动更新，需要重新生成；旧草稿还需补齐实际采用的引用。

本版图片为SVG教学示意，不是任意文生图或真实蛋白质三维模型。数学图表达有限模型，科学解释与论文结论仍需对照原文。

## 安装与回退

现有安装不会因git pull自动改变。完成新版审查后，将 package.json、LICENSE、src 和 ops/verify-agh-trace.mjs 放入 AGH 工作目录下**新的独立快照目录**。使用 AGH“从新来源更新”，输入 `file:./work/<新目录>`，检查版本0.4.2与实际摘要后更新启用；也可用AGH官方SDK更新。不要删除旧快照或直接覆盖已安装目录。

AGH状态应同时显示 version=0.4.2、actualVersion=0.4.2、actual=running、trusted=true 才能判定生效。失败时读取具体操作记录，使用受支持的rollback；不手动删除运行中的快照。本机保留0.4.1回退目标，详见本次验证记录。
