# 模型与 AI 辅助使用声明

以下区分团队使用声明、API/配置标识和运行记录，避免将 AGH 宿主与 Agnes 模型混为一谈。模型 API 的路由别名不必然等同于可独立核验的上游权重版本。

| 模型名称 / 版本标识 | 提供方 / 接入服务 | 使用环节 | 调用方式 | 披露依据 |
|---|---|---|---|---|
| ChatGPT / GPT，`6.1sol` | 意心 AI（团队声明的 API 接入提供方） | 代码生成 | Codex 调用 API Key | 团队声明 |
| GPT-6 Astra，原填 `6alstra`，团队已确认名称 | 意心 AI | 代码生成 | Codex 调用 API Key | 团队声明 |
| ChatGPT / GPT，`5.6sol` | 意心 AI | 代码生成 | Codex 调用 API Key | 团队声明 |
| ChatGPT / GPT，`6.1sol` | 意心 AI | AGH 插件效果试验 | AGH 调用 API Key | 团队声明 |
| GPT-6 Astra，原填 `6.0alstra`，团队已确认名称 | 意心 AI | AGH 插件效果试验 | AGH 调用 API Key | 团队声明 |
| ChatGPT / GPT，`5.6sol` | 意心 AI | AGH 插件效果试验 | AGH 调用 API Key | 团队声明 |

系统配置还列有 `deepseek-v4-pro`（显示名 `DeepSeek V4 Pro`），作为已配置的可选模型披露，不将“出现在可选配置”写成“已经实际调用”。

意心 AI 在此表示接入提供方，不据此认定底层模型的原始研发方。`sol` / `Astra` 等标签按团队提供的调用名称披露，不擅自映射为其他正式产品版本。诊断中 Agnes Harness 软件版本 `0.0.0` 是宿主版本字段，不是 Agnes 模型版本。

模型用于协助生成代码、理解材料及组织工具参数；引用校验、渲染与测试由代码执行。SVG/HTML 为程序化生成，当前渲染流程未使用 Tripo、文生图模型或额外视觉生成 API。工具轨迹不等同于模型内部隐藏推理。
