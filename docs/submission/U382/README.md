## 评委快速体验

1. 解压整个作品包，用 Edge / Chrome 打开根目录 `开始体验.html`，点击离线互动示例。不需要登录、API Key 或安装依赖。
2. 查看 `01_申报材料` 的项目、技术和模型声明；查看 `04_运行证据` 的人工核查索引和原生事件。
3. 双击 `02_可运行作品/SciViz-AGH-0.4.2-Setup.exe` 查找 Windows / WSL 后台目录并解压，然后在 AGH 插件管理粘贴助手显示的来源并安装、信任和启用。也可手动使用同目录 ZIP。具体步骤见安装说明；真实模型交互需要评委自己的 AGH 模型配置，包内不含参赛者密钥。
4. 有 Node.js 24 及以上时，在作品包根目录执行 `node 05_测试样例/reproduce.mjs`，重跑三类输入与回归测试。只写入新的带随机后缀目录，不覆盖已有证据。
