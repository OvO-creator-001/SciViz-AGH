# SciViz-AGH 项目申报书

## 一、基本信息

项目名称：**SciViz-AGH——论文可视化可行性评估与交互式科普图解插件**。

组别：本科生组；参赛编号：U382；队伍名称：Sleep Early Unity；队长：富云杰。

参考方向：AI 驱动科学发现和设计、交叉应用。

### 项目摘要

SciViz-AGH 是面向本科生科学阅读的 AGH 插件。它将模型对论文或科学材料的理解，转化为有来源索引、可交互、可离线分享的 HTML/SVG 图解。AGH 负责文档读取、模型规划、工具调用与原生执行记录；插件负责结构化草稿、术语背景研究、引用约束、可视化可行性判断和页面渲染。作品提供学术与通俗两种解释，支持流程、分层、网络关系及柱状、折线、散点图，优先使用免费程序化渲染，不依赖付费图像或 3D 生成服务。每次生成保留独立产物和校验信息；证据不足时输出缺口，来源尚未人工核对时可生成并明确提示核查与版权风险。当前提交版本为 0.4.2，目标是帮助读者理解材料，而不是替代专业审稿或物理仿真。

### 问题来源与目标

问题源于团队的论文阅读、跨专业学习和科普展示需求：论文中的术语、过程和数据关系难以直接理解；通用生成图片难以保留精确文字、引用和数据；单一思维导图又不足以表达不同结构。

目标是形成“阅读材料—组织证据—解释与修订—选择图解—生成离线页面”的可检查闭环，使读者能在理解结论的同时追溯其来源。当前不是通用 PDF 自动解析器，也不声称适配全部论文；主图结构化输入限制为 3–8 个节点、最多 16 条关系，服务于分段讲解。

## 二、技术信息

### AGH 的作用

通过 `package.json` 的 `agnes.plugins` 声明入口，由 AGH 插件系统加载 ESM 模块，并通过扩展接口注册工具。模型根据工具描述与 schema 选择调用；不依赖虚构的意图标签扫描或 YAML 插件接口。

AGH 提供模型接入、文档读取、工作区与会话上下文、权限治理、公共网络能力及原生 trace。插件提供领域约束和渲染实现。trace 是平台能力；本项目增加可核查的来源引用、草稿修订和产物清单，不将平台日志称为自研隐藏思维链。

已有评估/生成工具支持 `assess_visualization_feasibility`、`generate_visualization`。新版支持分阶段分析、术语研究、保存/审阅/修订草稿及 `render_sciviz_draft`，完整定义以源码和安装指南为准。

### 实现与边界

- 免费优先：核心 SVG/HTML 渲染无第三方运行时依赖；浏览器可离线打开。AGH 模型调用仍可能产生费用，不将整个系统描述为无成本。
- 可行性判断采用来源引用、结构与输入约束，不使用未经标定的主观加权百分比分数。
- 自动选择流程、分层或网络关系布局；显式数值输入可渲染柱状、折线、散点图，不从标题编造数据。
- 双模式解释、分步教学图、来源展开和节点交互；公共背景来源与原文来源分开，背景资料不替代原文结论证据。
- 来源 `verified` 不是生成的前置阻塞；生成结果和网页末尾均有核查及版权声明。无来源引用、非法引用和不安全输入仍按契约处理。
- 输出独立目录，保留旧版本；草稿按会话隔离；网络失败不伪装成成功查证。

### 数据、代码、专业软件与接口

| 项目 | 实际使用方式 |
|---|---|
| 输入数据 | 用户提供的论文/科学材料，由 AGH 文档工具读取；团队合成夹具用于可重复测试，明确标为非真实研究 |
| 背景资料 | 通过 AGH Host 公共网络接口读取教材/学术页面，保留 URL、时间、摘录与截断标记 |
| 代码 | 团队 JavaScript ESM 插件，Node.js ≥24，MIT；源码固定提交见总览 |
| AGH | Agnes Harness 插件宿主；已有记录包含 WSL2/Linux、Node 24.21.0；本次离线复测使用 Windows Node 24.20.0 |
| 浏览器 | HTML/SVG/CSS/JavaScript；历史浏览器检查使用 Edge，相关版本和结果随证据提供 |
| API | 模型 API 由 AGH 管理；开发阶段通过 Codex/API 辅助编码；模型清单见独立声明，不附 Key |
| 专业软件/仿真/设备 | 当前运行闭环不依赖专业仿真软件、物理设备接口或 3D 生成 API；不能据此声称完成科学仿真验证 |

初期规划曾考虑 Tripo、Three.js、3D 模型及加权评分，当前提交不将这些未落地路线算作运行功能。通用关系图、数值图和教学图是本版本的实际实现。

## 三、可运行作品与验证

安装包、离线示例、固定代码和复现说明均随包提供。网站与仓库入口见根目录总览。可离线复测不需要 GitHub 访问权限；AGH 模式需要宿主已配置可用模型并授予所需工作区权限。

验证包括结构与引用契约、图表输入保真、错误传播、会话隔离、重复生成不覆盖、HTML 文本转义及离线页面行为。0.4.2 回归包含 36 项自动测试，详细结果见测试目录；历史原生 AGH 调用展示评估、生成与 `rendered` 状态，保留对应版本信息。

专业验证范围是可视化表达与输入数据的一致性，以及明示教学公式的数值行为；没有将自动测试等同于领域专家审阅，也不宣称论文结论得到独立实验验证。
